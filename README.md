# المقامات الشرقية

دليل صوتي تفاعلي لتعلّم المقامات العربية الثمانية الأساسية (الرست، البيات، السيكاه، الصبا، الحجاز، النهاوند، الكرد، العجم)، وتفرّعاتها في بلاد الشام واليمن والحجاز ومصر والعراق والمغرب العربي، مع إيقاعات الإنشاد، وأنواع الموّال، وأناشيد إسلامية، واختبار لتدريب الأذن، وميزة تجريبية للتعرّف على المقام من صوتك.

## الملفات

- `index.html` — الصفحة الرئيسية (البنية)
- `styles.css` — التنسيق والمظهر
- `app.js` — البيانات والمنطق (تشغيل الأصوات، الإيقاعات، الاختبار، التعرّف على الصوت)

## التشغيل محلياً

يكفي فتح `index.html` في أي متصفح حديث. لعمل ميزة «غنِّ لي» (الميكروفون) بشكل صحيح، يحتاج المتصفح أن تُعرض الصفحة عبر `https://` أو `http://localhost` — فتحها كملف محلي مباشرة (`file://`) قد يمنع المتصفح من السماح بالميكروفون.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع الملفات الثلاثة (`index.html`, `styles.css`, `app.js`) إلى الفرع الرئيسي.
2. من إعدادات المستودع Settings → Pages، اختر Source: `Deploy from a branch`، والفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة أو دقيقتين سيظهر رابط من نوع:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
4. افتح الرابط — ستعمل جميع الميزات بما فيها الميكروفون لأن الصفحة أصبحت مستقلة وتُعرض عبر HTTPS.

## ملاحظات

- جميع النغمات مولَّدة إلكترونياً (Web Audio API) لتوضيح أبعاد كل مقام، وليست تسجيلات حقيقية.
- الأمثلة أناشيد وابتهالات ومواويل إسلامية فقط؛ تصنيفها المقامي اجتهادي وليس موثّقاً أكاديمياً — تحقق بأذنك دوماً.
- ميزة «غنِّ لي» تقدير تقريبي للتدريب والتسلية، وليست اختباراً معتمداً.
