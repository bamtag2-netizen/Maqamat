ثمانية مقامات أساسية، بمفاتيحها وأجناسها، ثم تفرّعاتها في الشام واليمن والحجاز ومصر والعراق والمغرب العربي — مع إيقاعات الإنشاد، وأنواع الموّال، وأناشيد إسلامية، واختبار لتدريب الأذن. اضغط أي دائرة أو زر للاستماع.

ملاحظة: النغمات هنا مولَّدة إلكترونياً لتوضيح أبعاد كل مقام (المسافات بين درجاته) وليست بديلاً عن سماع آلات حقيقية كالعود والقانون. اخترنا طبقة صوتية موحّدة لكل المقامات لتسهيل المقارنة بينها، مع ذكر اسم درجة القرار العربية التقليدية لكل مقام. الأمثلة كلّها أناشيد وابتهالات ومواويل دينية إسلامية فقط (لا أغانٍ دنيوية)، وتصنيفها المقامي اجتهادي غير موثّق أكاديمياً — لا يمكن تضمين تسجيلات صوتية حقيقية مباشرةً لأنها محمية بحقوق الملكية، ولذلك وُضع بجانب كل مثال زر يفتح بحثاً مباشراً عنه في يوتيوب لتسمعه بصوته الأصلي وتتحقق بنفسك من مطابقته للمقام. أما اختبار «غنِّ لي» فتقدير تقريبي فقط ولا يغني عن أذن مدرّب مختص، ويحتاج تشغيل الصفحة عبر رابط HTTPS (كـ GitHub Pages) حتى يعمل المتصفح على السماح للميكروفون.
